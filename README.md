## What this repository is

`aeon-lab` is a historical/experimental engineering workspace used by Adaptive Liquidity to explore agent-harness workflows, orchestration, MCP tooling, research automation, governance, provenance, and related lab infrastructure.

It should be read as a **lab repository**, not as an Adaptive Liquidity product, not as an Asentxia product, and not as evidence that Adaptive Liquidity created ECC.
